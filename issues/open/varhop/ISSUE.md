# Issue: varhop

- [prompt-core](prompt-core/brief.md): pure ES-module logic for importing prompt files, `{{NAME}}` tokens, copy rebuild, search ranking and usage decay, loadable by bun and QML.
- [repo-sync](repo-sync/brief.md): a CLI that lists repos, clones and pulls one private GitHub prompt repo with the stored gh login, and writes one verified library bundle.
- [overlay-plugin](overlay-plugin/brief.md): the `ivan.varhop` Omarchy overlay plugin (search, editor, settings, copy, keys, usage) wired to prompt-core and repo-sync.
